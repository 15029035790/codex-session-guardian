# Contributing

Thanks for helping improve Codex Session Guardian.

## Before opening a pull request

1. Keep changes focused and explain the user-visible behavior they change.
2. Do not include Codex conversation content, prompts, responses, source code from monitored projects, local databases, logs, or screenshots containing private task titles and paths.
3. Run:

   ```bash
   swift build
   .build/debug/codex-session-guardian-tests
   ```

4. Separate runtime proof from static tests. A successful build does not prove hover, drag, menu bar, or multi-display behavior.

## Character assets

New character assets must include their source, author, checksum where practical, and exact redistribution terms. Do not label non-commercial assets as open source. Contributions that create trademark, copyright, or unclear provenance risk may be declined.

By submitting code or documentation, you agree that your contribution may be distributed under the MIT License. Asset contributions remain subject to their explicitly documented terms.
